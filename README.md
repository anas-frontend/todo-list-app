# Todo List App

My first JavaScript project. A todo list where every task has a priority.

## Features

- Add a task with a priority (Normal / Important / Urgent)
- Mark a task as done
- Edit a task (Enter saves, Escape cancels)
- Delete a task
- Filter: All / Pending / Completed
- Counter for the tasks and the completed ones
- Button to clear all the completed tasks

## Built with

HTML, CSS and JavaScript. No libraries.

## How to run

Open `index.html` in your browser.

## Notes

The tasks are not saved, they reset when you refresh the page. Saving them with localStorage is the next step.
